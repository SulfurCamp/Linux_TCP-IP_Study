# Raspberry Pi IoT & TCP/IP Programming Examples

이 폴더는 라즈베리 파이 환경에서 진행된 IoT 및 TCP/IP 통신 프로그래밍 실습 코드들을 포함합니다. 주로 C 언어로 작성되었으며, 네트워크 프로그래밍의 기본부터 고급 주제까지 다양한 예제들을 다룹니다.

## 학습 가능한 주요 개념

*   **소켓 프로그래밍 기초:** TCP/UDP 소켓 생성, 연결, 데이터 송수신
*   **클라이언트/서버 모델:** 기본적인 클라이언트 및 서버 구현
*   **멀티프로세스/멀티스레드 프로그래밍:** 동시성 처리를 위한 프로세스 및 스레드 활용
*   **I/O 멀티플렉싱:** `select` 함수를 이용한 다중 소켓 관리
*   **IoT 센서 데이터 처리:** 간단한 IoT 서버 구현을 통한 데이터 수신 및 처리
*   **리눅스 시스템 프로그래밍:** 파일 I/O, 프로세스 제어 등

## 폴더 및 파일 설명

### `TCPIP_Src` 폴더

이 폴더는 TCP/IP 통신 관련 서적 또는 강의의 챕터별 예제 코드 모음입니다. 각 챕터는 특정 TCP/IP 개념을 다루며, 점진적으로 복잡한 네트워크 프로그래밍 기술을 소개합니다.

*   **Chapter 1-5:** 소켓 생성, 주소 할당, 연결 설정, 데이터 송수신 등 기본적인 TCP/IP 소켓 프로그래밍 개념.
*   **Chapter 6-10:** 멀티프로세스 및 멀티스레드를 이용한 동시성 서버 구현, 프로세스 간 통신 (IPC).
*   **Chapter 11-15:** `select`, `poll`, `epoll`과 같은 I/O 멀티플렉싱 기법을 활용한 다중 클라이언트 처리.
*   **Chapter 16-20:** UDP 통신, 브로드캐스트, 멀티캐스트 등 비연결형 통신 프로그래밍.
*   **Chapter 21-24:** 고급 소켓 옵션, 도메인 소켓, Raw 소켓 등 심화된 네트워크 프로그래밍 주제.

### 개별 `.c` 파일들

*   `hello_client.c`, `hello_server.c`: 가장 기본적인 TCP 클라이언트-서버 통신 예제. 클라이언트가 서버에 연결하여 간단한 메시지를 주고받는 기능을 구현합니다.
*   `iot_server.c`: IoT 디바이스로부터 데이터를 수신하는 서버 예제. 센서 데이터와 같은 정보를 네트워크를 통해 받아 처리하는 시나리오를 가정합니다.
*   `select_client.c`: `select` 함수를 사용하여 여러 파일 디스크립터(소켓, 표준 입력 등)의 이벤트를 동시에 감지하고 처리하는 클라이언트 예제. I/O 멀티플렉싱의 개념을 이해하는 데 도움이 됩니다.
*   `thread_client.c`, `thread1.c`: 스레드를 활용한 클라이언트 또는 서버 예제. 동시성 처리를 위해 스레드를 생성하고 관리하는 방법을 보여줍니다.

### 기타 파일

*   `idpasswd.txt`: 예제 코드에서 사용될 수 있는 ID 및 비밀번호 정보가 포함된 텍스트 파일 (실제 사용 시 보안에 유의).
*   `Makefile`: C 소스 코드들을 컴파일하고 실행 파일을 생성하기 위한 빌드 자동화 스크립트.
*   `mount.sh`: 리눅스 환경에서 파일 시스템을 마운트하는 데 사용될 수 있는 쉘 스크립트 예제.

## 컴파일 및 실행 (예시)

대부분의 C 소스 파일은 GCC 컴파일러를 사용하여 컴파일할 수 있습니다.

```bash
# Makefile이 있는 경우
make

# 개별 파일 컴파일 (예시)
gcc -o hello_server hello_server.c
gcc -o hello_client hello_client.c

# 실행 (예시)
./hello_server
./hello_client
```
