# Linux_TCP_IP: Linux Network Programming, IoT, and System Programming

이 폴더는 Linux 환경에서 TCP/IP 네트워크 프로그래밍, IoT 애플리케이션 개발, 그리고 다양한 리눅스 시스템 프로그래밍 기법을 학습하기 위한 예제 코드들을 포함합니다. 이전에 `Linux_code`와 `Raspberry_code` 폴더에 있던 내용들이 통합되어, 리눅스 기반의 네트워크 및 시스템 개발에 대한 포괄적인 자료를 제공합니다.

## 학습 가능한 주요 개념

*   **TCP/IP 소켓 프로그래밍:** 클라이언트-서버 모델, TCP/UDP 통신, 멀티프로세스/멀티스레드 서버, I/O 멀티플렉싱(select, poll) 등.
*   **리눅스 시스템 프로그래밍:** 프로세스 관리(fork, exec), 시그널, 파일 I/O, IPC(파이프, 공유 메모리 등).
*   **IoT 애플리케이션 개발:** 센서 데이터 수집, 통신 모듈(Wi-Fi, Bluetooth) 연동, 데이터 전송 및 제어.
*   **임베디드 리눅스 환경:** 라즈베리 파이와 같은 임베디드 보드에서의 프로그래밍.

## 폴더 구조 및 주요 파일 설명

이 폴더는 다양한 C 언어 기반의 네트워크 및 시스템 프로그래밍 예제들을 포함합니다.

*   **`TCP ChapterXX` 폴더들:**
    *   `TCP Chapter10`, `TCP Chapter10 0508`, `TCP Chapter11 0508` 등: TCP/IP 네트워크 프로그래밍 관련 챕터별 예제 코드. 소켓 생성, 연결, 데이터 송수신, 에코 서버/클라이언트, 멀티프로세스/멀티스레드 서버 구현 등을 다룹니다.
*   **`0508 부모 자식 프로세스 코드 (TCP_Chapter10)`:** `fork()`를 이용한 부모-자식 프로세스 생성 및 통신 예제.
*   **`0509 리눅스 과제`, `0513 리눅스과제`, `0520 리눅스 평가과제`, `5월 휴가 과제`:** 리눅스 시스템 프로그래밍 또는 네트워크 프로그래밍 관련 과제 코드.
*   **`라즈베리파이 IoT 실습`:** 라즈베리 파이 환경에서의 IoT 관련 실습 코드.
*   **`평가 프로그램`:** 특정 평가를 위한 프로그램 코드.
*   **`Raspberry_code` (통합된 내용):**
    *   `TCPIP_Src`: 라즈베리 파이 환경에서의 TCP/IP 통신 관련 챕터별 예제.
    *   `hello_client.c`, `hello_server.c`, `iot_server.c`, `select_client.c`, `thread_client.c`, `thread1.c`: 라즈베리 파이에서 실행되는 C 언어 기반의 TCP/IP 통신 및 IoT 관련 코드.
*   **`wifi_client_v1_idpass`:** ESP8266 Wi-Fi 모듈을 사용한 Wi-Fi 클라이언트 예제.
*   **개별 `.c` 파일:**
    *   `0522blink원본main.c.txt`: 특정 날짜의 blink 예제 원본.
    *   `hello_client.c.png`, `hello_server.c.png`: C 소스 코드의 이미지 파일.

## 빌드 및 실행 방법 (일반적인 절차)

대부분의 C 소스 파일은 GCC 컴파일러를 사용하여 컴파일하고 실행할 수 있습니다.

```bash
# C 소스 파일 컴파일 예시
gcc -o my_program my_program.c -lpthread -lbluetooth # 필요한 라이브러리 추가

# 실행 예시
./my_program
```

네트워크 프로그래밍 예제의 경우, 클라이언트와 서버를 각각 다른 터미널에서 실행해야 할 수 있습니다.

## 참고

이 폴더의 예제들은 다양한 리눅스 시스템 및 네트워크 프로그래밍 개념을 다루고 있습니다. 각 예제에 대한 상세한 설명은 해당 소스 코드 내의 주석이나 별도의 문서에서 찾아볼 수 있습니다.
